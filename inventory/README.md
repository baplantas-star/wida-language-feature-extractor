# WIDA feature inventory

`features.json` lists every language feature defined in the WIDA Language Charts'
"Definitions and Examples" section (source S1 in `reference/sources.md`), 70 entries.
It is the only place WIDA terminology enters the code. `widaName` is copied
exactly from the source.

## Shape of one entry

```json
{
  "id": "modal-verbs",
  "widaName": "Modal verbs",
  "parent": null,
  "dimension": "word",
  "group": null,
  "source": { "ref": "S1", "page": 32 },
  "chartTerms": ["modal verbs"],
  "chartMentions": [
    { "page": 15, "gradeCluster": "Grades 4–5", "mode": "expressive",
      "level": "Level 6", "column": "word/phrase", "term": "modal verbs" }
  ],
  "mapping": {
    "tier": "lexical",
    "construct": "What the detector looks for",
    "rationale": "Why that is evidence of the WIDA feature",
    "status": "unvalidated",
    "reviewedBy": null,
    "reviewedOn": null
  },
  "detectors": ["modal-verbs.word"]
}
```

| Field | Meaning |
|---|---|
| `id` | Our short, stable name used in code and tests (not WIDA's). |
| `widaName` | The term exactly as WIDA prints it. |
| `parent` | The broader WIDA term it sits under, if any (e.g. Demonstratives → Cohesive devices). |
| `dimension` | `discourse`, `sentence`, or `word` (WIDA's Word/Phrase dimension), per the section of S1 it is defined in. |
| `group` | WIDA's sub-heading, when there is one (e.g. "Linking Ideas Within and Across Sentences"). |
| `source.page` | Page in S1 where the term is defined. |
| `chartTerms` | Exact phrases from the chart descriptors that refer to this feature. Chosen by Claude; Brett to review. |
| `chartMentions` | Chart cells containing one of those phrases. Generated by `build/link_charts.py`, not typed by hand. Recorded for reference only: the app never turns a detection into a proficiency level. |
| `mapping.tier` | `lexical` (word lists and simple patterns), `parse` (needs grammar parsing), `interpretive-candidate` (a possible instance a reader must confirm), or `null` when there is no detector. |
| `mapping.status` | `no-detector`, `unvalidated` (default for a new detector), `reviewed` (Brett checked the rationale), or `validated` (measured on an annotated set Brett approves). |
| `detectors` | `ruleId`s of the detectors that produce this feature. |
