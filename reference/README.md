# Reference

The WIDA source documents themselves are **not** stored in this repository.
Brett keeps his own copies. This folder records which documents (and which
editions) the inventory is based on, so every WIDA term in
`inventory/features.json` can be traced to a specific page.

- `sources.md` — the list of WIDA documents in use, each with a short ID (S1, S2, …).

Claude does not fetch, download, or reproduce WIDA documents. WIDA feature
names, levels, grade bands, and Key Language Uses enter the inventory only as
Brett supplies them, copied exactly from his copy and cited by source ID and
page.
